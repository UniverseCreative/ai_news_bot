Cursor capitalizes on GitHub frustration, launches rival hosting platform

📅 2026-08-19 07:38 ⏱️ زمان مطالعه: حدود ۲ دقیقه

از همواره، GitHub به‌عنوان میزبان کد موردعلاقه‌ی اغلب توسعه‌دهندگان شناخته شده است. با این حال، در زمان‌های اخیر، این پلتفرم با مشکلاتی از جمله قطعی‌های گسترده و کاهش عملکرد مواجه شده و در این شرایط، Cursor آماده است تا این ضعف‌ها را پر کند.

این استارتاپ هوش مصنوعی که به‌طور رسمی بخشی از SpaceX محسوب می‌شود، این هفته پلتفرم جدیدی به نام Origin را راه‌اندازی کرد — یک پلتفرم میزبانی کد که به گونه‌ای طراحی شده است که تمام کارهایی را که توسعه‌دهندگان معمولاً با GitHub انجام می‌دهند، انجام دهد: همکاری در پروژه‌های کد، مرور و ویرایش آنها، مدیریت درخواست‌های ادغام (ویرایش‌های انجام‌شده توسط دیگران که درخواست دارند به کد اصلی اضافه شوند) و ذخیره‌سازی آنها در مخازن.

به نظر می‌رسد این یک گام طبیعی برای Cursor باشد که تا به امروز تمرکزش بر فروش خدمات توسعه وب خودکار از طریق AI Code Editor بوده است. Cursor همچنین اعلام کرده است که ویژگی‌های "مخصوص عامل" به زودی برای Origin در دسترس خواهد بود، اگرچه هنوز جزئیات زیادی به اشتراک گذاشته نشده است. این شرکت همچنین می‌گوید که در حال ساخت یک "اکوسیستم اپلیکیشن" گسترده‌تر برای حمایت از تلاش‌های کدنویسی در Origin است.

جالب است که استفاده از Origin نیاز به توقف استفاده از GitHub ندارد. در واقع، Origin به گونه‌ای طراحی شده است که به توسعه‌دهندگان اجازه می‌دهد که کنار GitHub کار کنند و کدها را به‌صورت interoperable بین این دو رد و بدل کنند.

Cursor در وبلاگ خود می‌گوید: "مخازن GitHub شما می‌توانند در کنار آنهایی که Cursor میزبانی می‌کند، قرار بگیرند. GitHub را به Cursor متصل کنید، سازمان خود را انتخاب کنید و مخازنی را که می‌توانید همگام‌سازی کنید، مشاهده خواهید کرد. یکی را انتخاب کنید و Cursor آن را وارد می‌کند."

راه‌اندازی Origin با ناامیدی‌های گسترده‌ای نسبت به افت خدمات GitHub همزمان شد. در واقع، در همان روزی که Cursor پلتفرم جدید خود را راه‌اندازی کرد، GitHub با قطعی جهانی نسبتاً طولانی‌مدت مواجه شد. به مدت بیش از شش ساعت، عملکردهای این سایت به‌طور گزارش‌شده‌ای کاهش یافت و نرخ خطا در سطح جهانی نزدیک به 20 درصد بود.

این اولین بار نیست که چنین اتفاقی رخ می‌دهد. پیش‌تر در سال جاری، پس از وقوع چندین قطعی، GitHub اقداماتی جدید برای راضی کردن کدنویسان ناراضی اعلام کرد، چرا که به‌نظر می‌رسید مشکلات موجودی آن رو به افزایش است. به‌طور کلی، این پلتفرم در سال گذشته 257 قطعی را تجربه کرده است، طبق تحلیل اخیر LeadDev. این مشکلات مداوم به "خروج قابل‌مشاهده کاربران با پروفایل بالا" منجر شده است، به‌گفته‌ی خبرنگار LeadDev، چارلز هومبل.

با این حال، اگر Cursor بخواهد با GitHub رقابت کند، کار سختی پیش‌رو دارد. طبق معیارهای خود GitHub، حدود 180 میلیون توسعه‌دهنده از این پلتفرم در آخرین ماه‌های گذشته استفاده می‌کنند. این پلتفرم که در سال 2007 تأسیس و در سال 2012 به‌دست Microsoft خریداری شد، همچنان بزرگ‌ترین میزبان کد منبع در جهان است.

زمانی که از طریق لینک‌های موجود در مقالات ما خرید می‌کنید، ممکن است کمیسیون کوچکی کسب کنیم. این امر بر استقلال و بی‌طرفی تحریریه ما تأثیری ندارد.

سریع‌تر مقیاس‌بندی کنید. پرتفولیوی خود را گسترش دهید. تجربه عملی کسب کنید. مهم نیست که هدف شما چیست، Disrupt می‌تواند به شما قدرت بدهد. امروز تا 300 دلار صرفه‌جویی کنید!
