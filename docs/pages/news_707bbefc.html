NVIDIA Releases TensorRT Model Connect in Public Preview: Hugging Face Checkpoint to Native C++ Inference in Two Commands

📅 2026-08-20 07:42 ⏱️ زمان مطالعه: حدود ۲ دقیقه

NVIDIA نسخه پیش‌نمایش عمومی TensorRT Model Connect (TRTMC) را منتشر کرده است؛ یک پروژه متن‌باز که با استفاده از یک چک‌پوینت پشتیبانی‌شده از Hugging Face یا محلی، به استنتاج کامل TensorRT در دو فرمان می‌رسد. در این فرآیند، مرحله صادرات ONNX وجود ندارد. این ساخت، یک اثر هنری نسخه‌بندی شده تولید می‌کند که از طریق APIهای وظیفه بومی C++ اجرا می‌شود، بنابراین استنتاج می‌تواند در یک سرویس C++، برنامه جاسازی‌شده یا کُنش رباتیک بدون PyTorch در مسیر اجرای خود، انجام شود. این پروژه تحت مجوز Apache-2.0 منتشر شده و به عنوان مجموعه‌ای از پیاده‌سازی‌های مرجع متعلق به خانواده عرضه می‌شود، نه یک مبدل عمومی واحد. NVIDIA همچنین اعلام کرده است که کل پروژه — پیاده‌سازی مدل‌ها، بهینه‌سازی عملکرد، آزمایش‌ها، یکپارچه‌سازی‌ها و مستندات — با استفاده از عوامل OpenAI Codex تحت نظارت و بررسی انسانی ساخته شده است.

بله، برای ارزیابی و کار یکپارچه‌سازی بومی، در شرایط واقعی. کد متن‌باز و قابل نصب است. چرخ‌ها در حال حاضر به سیستم‌عامل Linux aarch64 محدود است و نیاز به Python 3.10 یا 3.12، glibc 2.39 یا جدیدتر و TensorRT 11.1.0.106 دارد. چرخ‌های x86_64 منتشر نشده‌اند؛ کاربران x86_64 باید به مسیر ساخت منبع Docker بروند.

شروع سریع، Qwen3-0.6B را می‌سازد و اجرا می‌کند:

همان.bundle از C++ با trtmc::load("./qwen3-0.6b.bundle") بارگذاری می‌شود.

TRTMC ساخت و زمان اجرا را در یک اثر هنری نسخه‌بندی شده تفکیک می‌کند. Python مسئول حل چک‌پوینت و ساخت موتور TensorRT است. پروفایل‌های بومی سپس استنتاج را در C++ بدون PyTorch اجرا می‌کنند. تعداد کمی از پروفایل‌های ترکیبی یک اجرایی Python کمکی را فراخوانی می‌کنند و منیفست‌های آن‌ها به‌طور صریح این وابستگی را اعلام می‌کنند.

برنامه‌ها به APIهای وظیفه — generate()، transcribe()، generate_image()، embed()، solve() — فراخوانی می‌کنند، به جای اینکه مراحل تبدیل و چسباندن ویژه هر مدل را حفظ کنند. trtmc inspect نوع بسته، خانواده مدل، دقت، هویت زمان اجرا و موتور‌ها را افشا می‌کند که این امر باعث می‌شود اثر هنری قابل ذی‌حسابی باشد نه مبهم.

NVIDIA مسیر سنتی را به‌صورت PyTorch → ONNX یا TorchScript → TensorRT → یکپارچه‌سازی C++ خاص مدل ترسیم می‌کند و حالت‌های شکست را که حذف می‌کند، نام می‌برد: شکاف‌های صادرات، یکپارچه‌سازی تکراری برای هر مدل و اعتبارسنجی پخش‌شده بر روی چندین اثر هنری تبدیل.

به GitHub Repo مراجعه کنید. همچنین، لطفاً ما را در Twitter دنبال کنید و فراموش نکنید که به جامعه ML SubReddit با بیش از 150,000 عضو بپیوندید و به خبرنامه ما مشترک شوید. صبر کنید! آیا شما در تلگرام هستید؟ اکنون می‌توانید به ما در تلگرام نیز بپیوندید.
