AI Coding Agents for Enterprise: IP Indemnity, Data Residency and 500-Seat Cost Compared

📅 2026-09-27 12:50 ⏱️ زمان مطالعه: حدود ۲ دقیقه

راهنمای ما تحت عنوان «بهترین عوامل کدنویسی هوش مصنوعی و پلتفرم‌های توسعه» به بررسی عملکرد هر یک از عوامل کدنویسی هوش مصنوعی و جایگاه آنها پرداخته است. این متن برای دسته‌ای دیگر از خوانندگان نوشته شده است. این مطلب برای مسئول خرید، مشاور عمومی و بازبینی‌کننده امنیتی تهیه شده است.

این خوانندگان قبل از هر گونه پیاده‌سازی چهار سوال می‌پرسند. اگر کد تولیدشده ادعای مالکیت معنوی را ایجاد کند، چه کسی هزینه را پرداخت می‌کند؟ درخواست‌ها در کجا ذخیره می‌شوند؟ مدیران چه چیزی را می‌توانند ثبت کنند؟ هزینه واقعی 500 صندلی چقدر است؟

ما زبان قرارداد فعلی GitHub Copilot، AWS Kiro، Cursor، Devin و Windsurf را مورد بررسی قرار دادیم. هر اصطلاح زیر در تاریخ 26 سپتامبر 2026 با صفحات خود فروشنده بررسی شده است. این گزارش است و نه مشاوره حقوقی. شرایط نهایی را با مشاور حقوقی بررسی کنید.

Cognition Windsurf را خریداری کرد. در تاریخ 2 ژوئن 2026، Cognition ویرایشگر Windsurf را به Devin Desktop تغییر نام داد. اکنون Devin و Windsurf بر روی یک جدول قیمت‌گذاری و یک مجموعه از شرایط قرار دارند.

این بند مانع از پیاده‌سازی‌های شرکتی می‌شود. هر ردیف از قرارداد فعلی فروشنده استفاده می‌کند. نقل‌قول‌ها کوتاه و مستقیماً از منبع مرتبط استخراج شده‌اند.

GitHub Copilot: تغییرات Microsoft در تاریخ 3 آوریل 2026 بیشتر از هر راه‌اندازی ویژگی‌ای اهمیت دارد. پیش از آن، یک تنظیم اداری می‌توانست پوشش را باطل کند. صفحه لازم‌الاجرای Microsoft اکنون هیچ اقدام اضافی را برای پیشنهادات GitHub لیست نمی‌کند. محدودیت باقی‌مانده کلمه «تغییر نیافته» است. بیشتر کدهای فرستاده شده ویرایش می‌شوند، بنابراین از مشاور حقوقی بپرسید که تغییرات چه مقدار می‌تواند کد را خارج از دامنه قرار دهد.

AWS Kiro: Kiro حقایق جبران خسارت هوش مصنوعی تولیدی AWS را به ارث می‌برد. AWS آن را برای ادعاهای حق مؤلف مربوط به خروجی از خدمات ذکر شده در بخش 50.10 بدون محدودیت توصیف می‌کند. پوشش کاهش می‌یابد اگر ورودی‌های شما نقض کنند یا ویژگی‌های فیلتر را غیرفعال کنید. Kiro اعلام می‌کند که مشترکان پرداختی با این حفاظت همراه هستند.

Cursor: MSA در کاغذ گسترده‌ترین است. این قرارداد پیشنهادها را نام می‌برد و جبران خسارت را از سقف هزینه حذف می‌کند. استثناها به‌ویژه زمانی دردسرساز می‌شوند که ادعا به یک اصلاح یا ترکیب غیرمجاز مربوط باشد. شرایط خدمات مصرف‌کننده به صورت معکوس است: کاربران Anysphere را جبران خسارت می‌کنند.

Cognition (Devin، Windsurf): Cognition یک مورد استثنایی است. MSA این شرکت داده‌های مشتری را شامل خروجی‌ها تعریف می‌کند و سپس داده‌های مشتری را از جبران خسارت исключ می‌کند. بنابراین کد تولیدشده خارج از وعده استاندارد قرار دارد. جبران خسارت همچنین به 2 برابر هزینه‌های 12 ماه گذشته محدود شده است. هر پیاده‌سازی Devin یا Devin Desktop نیاز به اصلاحات در فرم سفارش دارد.

GitHub Copilot: برای کسب‌وکار و شرکت‌ها، سوالات متداول طرح‌ها می‌گویند که چت IDE و درخواست‌های تکمیل نگهداری نمی‌شوند. درخواست‌های دیگر سطوح، مانند github.com، موبایل و CLI، به مدت 28 روز نگهداری می‌شوند. داده‌های تعامل کاربران به مدت 2 سال حفظ می‌شود. GitHub بر اساس داده‌های کسب‌وکار یا شرکتی آموزش نمی‌دهد.

سازمان‌ها در GitHub Enterprise Cloud با محل سکونت داده‌ها می‌توانند استنتاج Copilot را به ایالات متحده یا اتحادیه اروپا محدود کنند. این سیاست 10٪ به مصرف اعتبار هوش مصنوعی اضافه می‌کند. هر منطقه همچنین لیست مدل محدودتری را ارائه می‌دهد.

AWS Kiro: مطابق با صفحه حفاظت داده‌های Kiro، محتوای شرکتی هرگز برای بهبود خدمات استفاده نمی‌شود. این داده‌ها در منطقه‌ای که نمایه Kiro شما پیکربندی شده است ذخیره می‌شود. استنتاج در داخل جغرافیای ایالات متحده یا اروپا باقی می‌ماند، به جز مدل‌های برچسب‌خورده آزمایشی. مدیران می‌توانند داده‌ها را با کلیدهای KMS مدیریت‌شده توسط مشتری رمزگذاری کنند.

Cursor: با فعال کردن حالت حریم خصوصی، Cursor هیچ توافق‌نامه حفظ داده‌ای با تمام تأمین‌کنندگان مدل ندارد و بر روی کد شما آموزش نمی‌دهد. محتوای فایل‌ها به طور موقت ذخیره می‌شود و با کلیدهای تولیدشده توسط مشتری رمزگذاری می‌شود. صفحات عمومی Cursor هیچ منطقه پردازش انتخابی مشتری را ارائه نمی‌دهند. هر درخواست هنوز از طریق زیرساخت پشت صحنه Cursor عبور می‌کند.

Cognition: MSA آموزش بر روی داده‌های مشتری را بدون اجازه کتبی ممنوع می‌کند.
